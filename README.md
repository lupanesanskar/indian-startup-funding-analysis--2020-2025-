# Indian Startup Funding Analysis 

I created a basic Dashboad or analysis of indian startup funding with the help of :
- Python for programming
- Pandas for Data Manipulation
- Matplotlib for Data Visualization
- Streamlit for UI

In this analysis I use the dataset of indian startup funding from 2020 to 2025.
Also from this analysis I understand that in startup there are multiple investors that are investing more amount of money in startup.
From 2020 to 2025, a total of ₹2,59,797.75 Cr was invested in 180 startups. I have presented all these facts and insights in this analysis.

Overall, from this analysis I nderstand multiple things that are related to startup that what are the investment types for investing money on startup, concept of subverical,industry verticals and funding trends.
